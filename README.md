# Fake News Detector

A machine learning project that classifies news as real or fake with a simple Streamlit interface.

## Features
- Detects fake and real news articles
- User-friendly Streamlit interface
- Machine Learning based prediction
- Fast and easy to use

## Technologies Used   
- Python
- Streamlit
- Pandas
- Scikit-learn

## Installation

```bash
git clone https://github.com/sumitbarsker/fake-news-detector.git
cd fake-news-detector
pip install -r requirements.txt
streamlit run app.py
```

## Usage
1. Enter news text in the input box.
2. Click the predict button.
3. View the prediction result.
